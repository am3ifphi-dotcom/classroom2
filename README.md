# 本質の残響 ── 帰れない放課後

桐葉高校の人物・世界観を用いた、**ゲーム独自の物語**の見下ろし型アクションRPG。
原作小説の事件や章立てを再現する作品ではありません。コマンドバトルではなく、移動・連撃・回避・範囲スキルをリアルタイムで操作します。

## すぐ遊ぶ

**[`release/honshitsu.html`](release/honshitsu.html) をダウンロードし、ブラウザで開いてください。**
画像、音源、日本語フォント、素材ライセンスを含む約4.8 MiBの単一HTMLです。プレイ中のCDN・外部API通信は不要です。初回の「放課後へ踏み出す」操作後に音が再生されます。

このセッションのライブプレビューでもプレイできます。

- 表示はビューポート全体を使用。ブラウザ自体の枠を消す全画面表示は、ゲーム右下の全画面ボタンから許可してください。埋め込み元・ブラウザによってはFullscreen APIが制限されます。
- `file://` の保存領域の扱いはブラウザによって異なります。長期的に同じ記録を使うなら、下記ローカルサーバー方式を推奨します。
- 音量・振動・粒子量はゲーム内手帳から変更可能です。

## 遊び方

| 操作 | キー |
|---|---|
| 移動 | WASD / 矢印 |
| 断章・三連撃 | J（長押し可）/ 左クリック |
| すり抜け・無敵回避 | Space / Shift / 右クリック |
| 本質解放・範囲攻撃・弾消し | Q（共鳴25消費、時間で回復） |
| ラムネ・HP回復 | R |
| 会話・調べる・会話を進める | E / Enter |
| 会話の全文表示・次へ | E / Enter / Space |
| 手帳・ポーズ | Tab / Esc（手帳内のTabはフォーカス移動） |

タッチ端末では左下の仮想スティックと右下のアクションボタンを使用します。ゲームパッドは左スティック移動、X攻撃、A回避、Yスキルに対応。調査・メニューはキーボードまたは画面ボタンを併用してください。

### 目的

1. 教室で三重・零と状況を確認し、黒板の前の綻びを調べる。
2. 影を鎮め、教室の綻びを修復する。
3. 東の渡り廊下から旧資料室と物理準備室へ。残る二つの綻びを修復する。
4. 渡り廊下の中心で最後の境界を越える。

三つの任意収集記録は、それぞれ最大HPを5増やします。綻びを修復するとレベル、HP、共鳴、攻撃力が上がります。教室の三重との会話でHPを回復できます。

修復済みの綻び・記録・残響・撃破数・プレイ時間をローカル保存します。敗北時や記録からの再開は教室から。HP・共鳴・ラムネを回復し、修復済みの綻びは維持します。戦闘途中の敵の配置は保存しません。

## 開発・ビルド

Node.js 22推奨。

```sh
npm ci
npm run dev -- --port 5173
# http://localhost:5173
```

```sh
npm test          # 純粋ロジック・衝突・経路・保存のテスト
npm run build    # dist/ へ静的サイト生成
npm run preview  # 本番ビルドの確認
npm run release  # dist/ から単一HTMLを生成
```

プレビューは0.0.0.0で待ち受け、Arenaの `.e2b.app` ホストに対応。アプリにサーバー処理やブラウザからのlocalhost APIアクセスはありません。

### ブラウザテスト

```sh
npm run dev -- --port 5173
npm run test:browser
node tests/standalone.mjs
```

Playwrightと `@sparticuz/chromium` を使用します。必要なOS共有ライブラリがない環境では、システムのChromiumを `CHROMIUM_PATH` で指定するか、必要なライブラリをセットアップしてください。この制作環境では同パッケージの `al2023.tar.br` 内のライブラリをローカルに展開し、`LD_LIBRARY_PATH` に指定しました。

ブラウザテストでは実際の画面操作に加え、戦闘・進行の検証を再現可能にする制御された敵配置を使用します。人間が全編を通しで手動プレイしたことや、すべての実機端末での動作保証を意味しません。

## 構成

- `src/game.js` — アクション、敵AI、攻撃予兆、レイヤー描画、カメラ、粒子。
- `src/world.js` — 外部アトラスの切り出し定義、4エリア、家具・衝突・接続。
- `src/characters.js` — 正規化した方向・フレーム仕様、待機の瞬き、人物の特徴。
- `src/story.js` — ゲームオリジナルの台詞・事件。
- `src/state.js` — 保存スキーマ検証、成長、当たり判定。
- `src/audio.js` — 外部音源のプール、音量、音楽切替。
- `src/main.js` / `src/style.css` — 日本語HUD、手帳、会話、入力、タッチ操作。
- `public/assets/` — 配布可能なゲーム用素材。提供画像は加工物のみ。
- `public/asset-sources.json` — 外部素材の取得元・固定blob・配置先。
- `public/CREDITS.md` / `public/licenses/` — 素材クレジット・利用条件。
- `tools/fetch-assets.py` — GitHubの固定blobから外部素材を再取得。
- `tools/character-art.py` — 外部の歩行ポーズを基にした32×48人物スプライトの再生成。
- `tools/prepare-assets.py` — アニメーション・ポートレート・エフェクトの加工。
- `tools/subset-fonts.py` — 使用文字に書体をサブセット化。台詞を追加したら再実行。
- `tools/standalone.mjs` — オフライン単一HTMLの生成。

外部素材はすでに同梱しているため、通常の起動・ビルドで素材取得やPythonの実行は不要です。加工の再実行には Pillow、フォントの加工には fonttools / brotli が必要です。人物ポートレートの元画像は同梱しません。再加工する場合のみ、権利者から入手した同じ画像を一時的に `google_drive/` に置き、作業後削除してください。

## 素材の利用条件

**LimeZu無料版は取得ライセンス上、非商用限定です。ゲーム全体を商用利用可能とは表示しません。**

その他の主な素材は、0x72（CC0）、ansimuz（CC0）、Morgan McGuire（CC0）、Kenney（CC0）、Abstraction（CC BY 4.0）、Micah Young（CC BY 3.0）、Lucide（ISC）、日本語書体（OFL 1.1）。加工内容を含む詳細は **[CREDITS.md](public/CREDITS.md)** を参照してください。

人物のフィールド表現は、参照画像を踏まえた外部スプライトの加工による解釈です。元の高解像度立ち絵の完全再現ではありません。原作・提供画像について、第三者向けの権利許諾は付与しません。

## 検証範囲

- 保存データの破損・不正値・保存拒否、成長計算、近接攻撃の方向と距離。
- 高速回避の壁抜け防止、全4エリアの目的地への到達可能性。
- デスクトップChromium：開始、会話、移動、攻撃、スキル、回避、ポーズ、全綻び、ボス第二段階、結末、敗北復帰、リロード後のセーブ。
- モバイル相当の390×844・844×390でタッチUIと画面のはみ出しを確認。
- 外部音源のブラウザ上でのデコード。
- 単一HTMLのオフライン起動と外部リクエスト不要の確認。

Safari / Firefox / 実機iOS・Androidでの動作と、各端末での音の実聴は未検証です。完成度を絶対評価する「最高品質」の客観的保証はできません。


## キャラクター修正版（v2）

- 元素材の方向順 R / U / L / D を、ゲーム内の L / U / R / D に並べ替え。歩行だけでなく、待機・回避・攻撃・残像・NPCの向きにも共通仕様を使用。
- 両馬：赤茶色の立ち上げ髪・額・角形眼鏡。三重：短い暗褐色の髪・斜めの前髪・眼鏡。零：長めの束状の黒髪・眼鏡なし・緩いネクタイ・黒い本。
- 頭部と胴体を独立した色検出で配置しない。全フレームで同じ首基準を使い、首が顎と襟の双方に重なるよう編集。腕・脚の元素材の動きを残しながら、制服の赤いチェック柄を除去。
- 手帳の「人物」で、3人の4方向・歩行／待機を実際のゲーム用アトラスで確認できます。
- `npm test` に方向・アトラス寸法・全フレーム範囲の回帰テストを追加。
- `.venv/bin/python tests/character-art.py` は全144フレームの顔の左右、後頭部、頭から足への画素の連結、零の本の連続性を確認。
- `node tests/characters-browser.mjs` は実際のA/W/D/Sと回避の方向、人物手帳の12方向表示と歩行／待機切替を確認。

## 横向きの首まわり修正版（v3）

- 顎側だけの接続では後頭部が浮いて見えるため、左右のうなじ・後ろ襟・肩の傾斜を再調整。両馬・三重の後頭部の輪郭も、うなじへ自然に細くなる形へ修正。
- 3人の左右×歩行／待機×6コマ、計72フレームに反映。共通の上下動基準を維持し、正面・背面、外部素材由来の手足の動きは維持。
- `.venv/bin/python tests/profile-art.py` で、後頭部の下に深い切れ込みがないこと、うなじから後ろ襟への支え、全フレームの接続位置の一致を確認。旧版の「顎から足まで画素がつながっているだけ」の検査とは別に実施。
- `node tests/characters-browser.mjs` は左右の全72コマが実際のCanvas描画でも欠けずに表示されることを確認。

## エリア移動の修正

- 移動先の出現位置を、戻り口の反応範囲外へ移動。移動直後0.65秒の操作ガードと、入口から離れるまでの再反応防止を追加。
- `npm test` で全6入口の出現位置・連打・往復・戦闘中の移動禁止を検証。
- `node tests/transitions-browser.mjs` で実際の歩行とE／Enterによる全エリア往復、長押し・連打・タッチボタンを検証。部屋移動そのものをテスト用ワープで代用しません。
